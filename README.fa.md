# glassmorphism-ui

<div dir="rtl" align="right">

یک **Agent Skill** که رابط کاربری هر پروژه‌ای را به طراحی **شیشه‌ای (Glassmorphism)** تبدیل می‌کند — **با همان رنگ‌هایی که پروژه از قبل دارد**.

نه پالت جدید. نه فریمورک جدید. نه مرحلهٔ build جدید.

## چه کاری می‌کند؟

اسکیل، ایجنت را در ده مرحله هدایت می‌کند:

| # | مرحله |
| --- | --- |
| ۱ | **شناسایی** — اول stack، مکانیزم پوسته و رنگ‌های موجود را گزارش می‌دهد، بعد کد می‌زند |
| ۲ | **استخراج توکن** — رنگ‌های خود پروژه را روی مجموعهٔ توکن‌های شیشه‌ای می‌نشاند |
| ۳ | **پس‌زمینهٔ aurora** — همان لایهٔ متحرک تار که باعث می‌شود شیشه اصلاً دیده شود |
| ۴ | **دستور شیشه** — یک سطح تار، اشباع‌شده و نیمه‌شفاف با لبهٔ روشن ۱ پیکسلی |
| ۵ | **حرکت** — بازخورد لمس، ورودها، پله‌ای شدن؛ فقط `transform` و `opacity` |
| ۶ | **اعمال** — بازطراحی همان اجزایی که پروژه از قبل دارد |
| ۷ | **راست‌چین / بومی‌سازی** — با logical properties چیدمان خودکار آینه می‌شود |
| ۸ | **دروازه‌ها** — کنتراست WCAG AA، اندازهٔ هدف، کاهش حرکت، fallback برای `@supports` |
| ۹ | **دام‌ها** — هفت اشتباهی که شیشه را خراب یا کند نشان می‌دهد |
| ۱۰ | **تحویل** — مرحله‌به‌مرحله، با توقف بعد از اولین صفحه |

### چرا مستقل از رنگ است؟

اسکیل هیچ‌وقت پالت تحمیل نمی‌کند. فقط یک **جدول نگاشت** می‌دهد:

| توکن | از چه چیزی استخراج می‌شود |
| --- | --- |
| `--primary` | رنگ برند / اکسنت خود پروژه |
| `--blob-1..4` | ۳ تا ۴ رنگ اشباع، مشتق از همان رنگ برند |
| `--glass` | رنگ سطح با شفافیت ~۵۵٪ |
| `--ring` | `--primary` با شفافیت ۳۵–۴۵٪ |

پس پروژه‌ای با برند سبز، شیشهٔ سبز می‌گیرد و پروژه‌ای با برند قرمز، شیشهٔ قرمز — هر کدام هویت خودش را نگه می‌دارد.

اسکیل یک پوشه است که `SKILL.md` دارد. چون نام پوشه باید با `name` یکی باشد، آن را **با نام `glassmorphism-ui`** کلون کن.

### Claude Code

```bash

git clone https://github.com/hoboho/glassmorphism-ui .claude/skills/glassmorphism-ui

git clone https://github.com/hoboho/glassmorphism-ui ~/.claude/skills/glassmorphism-ui
```

## دموی زنده

فایل [`examples/demo.html`](examples/demo.html) را در مرورگر باز کن — یک فایل تک‌پارچه و بدون هیچ وابستگی.

دو کنترل دارد:

- **theme** — روشن / تاریک
- **accent** — مقدار `--primary` را عوض می‌کند و کل پالت شیشه را در همان لحظه بازتولید می‌کند

رنگ اکسنت را عوض کن و ببین همهٔ سطوح، درخشش‌ها و گرادیان‌ها دنبالش می‌آیند. این همان ایدهٔ اصلی است: شیشه رنگ پروژه را به ارث می‌برد، نه این‌که رنگی را تحمیل کند.

## تنها نکته‌ای که باید یادت بماند

> **شیشه بدون چیزی در پشتش، فقط خاکستری است.**

`backdrop-filter` هرچه پشت عنصر باشد را تار می‌کند. روی پس‌زمینهٔ تخت چیزی برای تار کردن نیست، پس نتیجه مثل یک جعبهٔ خاکستری نیمه‌شفاف دیده می‌شود.
همیشه **اول لایهٔ aurora** را بساز، بعد شیشه را رویش.
